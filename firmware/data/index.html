Guide multi-univers

Une barre de 300 LEDs en Full Pixel nécessite 900 canaux DMX. Un univers ne contient que 512 canaux — il faut donc 2 univers. Chaque logiciel gère ce découpage différemment.

Mode Manuel
TouchDesigner (DMX Fixture POP)
Tu définis toi-même dans TouchDesigner quelle LED commence dans l'univers 2. Configure ici le même numéro de LED de départ que dans ton projet TD.
Univers 1
LEDs 1→170
Univers 2
LEDs 171→300
Bleu = univers 1 · Vert = univers 2
Mode Continuation
QLC+ · grandMA
Le logiciel continue les canaux DMX sans interruption. Une LED peut être coupée entre deux univers : R et G dans l'univers 1, B dans l'univers 2. Le firmware recolle les octets automatiquement.
Univers 1
ch.1→512
✂
Univers 2
ch.1→388
Rouge = LED coupée entre 2 univers (R/G dans U1, B dans U2)
Mode Pixel Aligné
Resolume Arena · Avenue
Resolume garantit que R, G et B d'un même pixel restent dans le même univers. Il saute 1 ou 2 canaux en fin d'univers 1 pour rester aligné sur des multiples de 3. Le firmware ignore ces canaux vides automatiquement.
